# FalseAlarm v1.5.0

## Install / upgrade

```bash
python -m pip install --upgrade falsealarm==1.5.0
```

## Highlights

- **JSON / form request-body injection** (`-X/--method`, `-d/--data`). Test
  APIs that take a body — including the **JSON login APIs** modern SPAs use,
  which have no HTML form to crawl:
  - **Login auth-bypass**: NoSQL operator objects (`{"email":{"$ne":null}}`)
    and SQL tautology (`' OR '1'='1`), re-verified; SQL hits report as `sqli`,
    NoSQL hits as `nosqli`.
  - Per-field SQL error/boolean/time and NoSQL operator injection on JSON
    (nested) and urlencoded bodies.

  ```bash
  falsealarm scan -u https://app.example.com/api/auth/login -m sqli,nosqli \
    -d '{"email":"a@b.com","password":"x"}'
  ```

- **AI triage via any OpenAI-compatible endpoint** — a local gateway, proxy or
  OpenAI — configured from env vars (no key on disk), taking precedence over
  Gemini:

  ```bash
  export FALSEALARM_LLM="openai/Combo1"
  export LLM_API_KEY="<key>"
  export LLM_API_BASE="http://192.168.10.103:20128/v1"
  falsealarm scan -u https://app.example.com -A --ai-triage
  ```
