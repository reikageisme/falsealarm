# FalseAlarm v1.4.0

A major upgrade that turns FalseAlarm from a recon mapper into a daily-driver
web assessment tool. Shipped as four ordered milestones (1.1.0 → 1.4.0); see
the [CHANGELOG](../../CHANGELOG.md) for each.

## Install / upgrade

```bash
python -m pip install --upgrade falsealarm==1.4.0
# optional extras
python -m pip install 'falsealarm[oast]'      # interactsh out-of-band testing
python -m pip install 'falsealarm[favicon]'   # Shodan-compatible favicon hashing
```

## Highlights

- **Nuclei-compatible `vulnscan`** — runs the community nuclei HTTP templates
  (~9.7k with `--oast`): path/raw requests, payloads, multi-step templates,
  all common matchers/extractors, via a sandboxed DSL. `falsealarm templates
  update` / `validate`.
- **Live terminal UI + reports** — a live dashboard (progress, req/s, status
  mix, findings by severity), copy-friendly finding lines, a summary table, a
  self-contained **`--html`** report, and a **`--fail-on`** CI gate.
- **Injection detection** — `sqli`, `nosqli` and `ssti` detect SQL / NoSQL /
  template injection on query parameters and forms, including **login
  auth-bypass**; every hit is re-verified. Detectors, not dumpers.
- **Out-of-band testing** — `--oast` enables interactsh templates for blind
  SSRF/RCE/XXE, reporting only on a real DNS/HTTP callback.
- **Daily-driver foundation** — authenticated scans (`-H`/`-b`), a scope guard
  (`--scope`/`--exclude-scope`), user config at `~/.falsealarm/config.yaml`,
  `--parallel` targets, and a stable home directory for history/`--diff`.
