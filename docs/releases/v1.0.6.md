# FalseAlarm v1.0.6

**AI-agent skill distribution is now built into the PyPI package.**

Install the release:

```bash
python -m pip install --upgrade falsealarm==1.0.6
```

Then install the bundled skill for your agent:

```bash
# Codex (default)
falsealarm install-skill --target codex

# Claude or the current project's .agents/skills directory
falsealarm install-skill --target claude
falsealarm install-skill --target project
```

Use `--force` to update an existing skill or `--destination <path>` to select a
custom final skill directory.

## What is included

- A maintained FalseAlarm skill covering authorized scan planning, output and
  pipe handling, diff/notification workflows, and troubleshooting.
- Development guidance for the async engine, discovered modules, DAG pipeline,
  YAML vulnerability templates, SQLite state, and the Go dirfuzz worker.
- UI metadata for agent skill discovery.
- Safe installation behavior: `pip install` never writes to an agent's home or
  project directory automatically.
- A working root-level `falsealarm --version` command.

## Verification

- The installed skill is sourced from the same canonical files shipped in the
  wheel, so the repository and PyPI guidance cannot silently diverge.
- Python tests cover custom installation, overwrite protection, project-local
  destination resolution, and invalid targets.
